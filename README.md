# MI Material Calculator

A native Android calculator built with Kotlin + Jetpack Compose Material 3. It uses Android dynamic colour on Android 12+ and follows an MI-inspired rounded keypad layout.

## Build the APK
1. Install Android Studio (latest stable) with Android SDK Platform 35.
2. Open this folder in Android Studio and allow Gradle sync.
3. Select **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
4. The APK will be at `app/build/outputs/apk/debug/app-debug.apk`.

Minimum Android version: Android 8.0 (API 26). No internet permission or account is required.
